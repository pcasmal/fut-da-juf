Publicar no GitHub (todos veem)

Publique manualmente: baixe o arquivo e suba no repositório (sobrescrevendo). Para publicar em 1 clique, veja Configurações avançadas no fim da página.

No manual: Add file → Upload files → arraste dados.json → edite o sw.js subindo a versão do cache → Commit.

Backup automático (tudo)
Salvar em arquivo Desconectado
Escolha um arquivo .json uma vez e o app grava tudo (elenco, futs, campeonato) automaticamente a cada alteração.
Backup manual completo (recomendado)
Baixa ou restaura tudo num arquivo JSON. Este é o único formato que restaura o app inteiro (elenco, futs, gols, times e campeonato).
Importar histórico (mesclar) 🗂️
Adiciona futs antigos (arquivo historico-juf.json) sem apagar nada do que já existe. Casa os nomes com o elenco atual e cria como inativos quem não existe. Pode reimportar quantas vezes quiser — ele substitui só o bloco histórico.
Planilhas CSV (para análise)
Baixa três CSVs: elenco, futs (formato longo: uma linha por jogador em cada fut, com gols/assistências/vitórias) e campeonato. Ótimos para abrir no Excel/Sheets. A importação por CSV cobre só o elenco.

Onde ficam os dados: tudo é salvo automaticamente neste navegador a cada alteração. Para não depender do navegador, conecte o arquivo de backup acima (JSON, Chrome/Edge) ou baixe o JSON de vez em quando. Os CSVs são cópias para leitura/análise, não para restaurar.

Itens sensíveis (notas dos jogadores e publicação automática). Toque para desbloquear com a senha.

Fase pelos últimos 3 futs
Em vez de comparar o mês atual, calcula a fase pelos últimos 3 futs que a pessoa jogou (vs. a média anterior dela).
✨ Revelação do ano
Escolha o melhor jogador novo de cada ano (quem começou a jogar naquele ano). Vira uma conquista no perfil dele.
