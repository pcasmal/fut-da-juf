Salvar em arquivo Desconectado
Escolha um arquivo .json uma vez e o app grava tudo (elenco, futs, campeonato) automaticamente a cada alteração.
Backup manual completo (recomendado)
Baixa ou restaura tudo num arquivo JSON. Este é o único formato que restaura o app inteiro (elenco, futs, gols, times e campeonato).
Planilhas CSV (para análise)
Baixa três CSVs: elenco, futs (formato longo: uma linha por jogador em cada fut, com gols/assistências/vitórias) e campeonato. Ótimos para abrir no Excel/Sheets. A importação por CSV cobre só o elenco.

Onde ficam os dados: tudo é salvo automaticamente neste navegador a cada alteração. Para não depender do navegador, conecte o arquivo de backup acima (JSON, Chrome/Edge) ou baixe o JSON de vez em quando. Os CSVs são cópias para leitura/análise, não para restaurar.
